# feath-models
Offline Persian TTS files for the Feath browser.

- diacritizer.onnx: ONNX int8 export of PedramR/canine-fa-diacritizer (MIT).
- piper_phonemize.*: trimmed build of piper-phonemize / espeak-ng (GPL-3.0).
- voice.onnx: rhasspy/piper-voices fa_IR magnoliasis medium (see its model card).
